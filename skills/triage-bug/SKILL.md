name: triage-bug
description: "An interview to gain a shared understanding of the bug and what the expected behaviour is."
disable-model-invocation: true
---

Run a `/interview` session to get to a shared understanding of the unintended behaviour as well as what the expected behaviour is. You are not concerned with solving the bug, but rather understanding it and the context in which it occurs.

Once complete ask the user if they wish to create a bug report using the '/to-bug-report' skill. If they do, tell them to invoke the `/to-bug-report` skill. Also advise the user that they can run a `/to-bug-report` session at any time to create a bug report from the current state of their current chat context.
